# AI Face Recognition Attendance System

A real-time AI-powered attendance system using face recognition and OpenCV.

## Features
- Real-time face recognition
- Unknown face detection
- Attendance CSV logging
- 1-minute cooldown system
- Absentee detection
- Multiple face support
- Improved UI

## Technologies Used
- Python
- OpenCV
- face_recognition
- NumPy

## Project Structure

FaceAttendance/
│
├── images/
├── main.py
├── README.md
├── requirements.txt

## How to Run

1. Clone the repository

2. Install required libraries

pip install -r requirements.txt

3. Add face images inside the images folder

4. Run the program

python main.py
